Sonar🔗ℹ

TuringLambdaAI

Public module: sonar

Sonar is in-memory vector search for Racket: chunk text, embed the chunks through an embedder you control, keep them in a store, and retrieve by similarity. The pure core never performs I/O against a provider — the embedding boundary is a parameter, and the Switchboard adapter (sonar/switchboard) is one explicit require away.

Sonar is not a database and not an agent framework. It holds corpora that fit in memory and answers "which passages resemble this query"; durability beyond one file is out of scope.
